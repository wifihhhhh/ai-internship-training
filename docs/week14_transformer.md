- Token 与字符有什么不同？

  字符是人眼看到的文字单位，Token 是模型处理文本时切分后的计算单位
- attention_mask 用来干什么？

  控制模型对序列中不同元素的关注度
- 为什么不同长度的输入需要 padding？

  对齐不同长度序列、实现同批并行的常规做法
- 为什么冻结 backbone？

  可以加快训练效率，也可以防止权值被破坏

- 只训练分类头，与微调整个 Transformer 有什么区别？

  前者能更好适应复杂任务但计算开销大，后者高效防过拟合但适应性受限。
- 测试指标是否高于随机猜测？如果没有，可能是什么原因？

  是。 原因可能有：1. 标签错误或数据噪声严重：训练或测试集中存在大量误标样本，导致模型学习到错误模式； 2. 模型过拟合或欠拟合：模型未能有效捕捉特征与标签之间的关系； 3. 类别预测方向错误：某些模型输出的概率与真实标签方向相反，只需将预测概率反转即可得到正确结果； 4. 样本不平衡处理不当：在类别分布极端不均衡的情况下，模型偏向多数类，影响判别性能。
